# Handoffs

One file per session that moved the map area, named `YYYY-MM-DD-slug.md`, newest
last. Each one answers three things and nothing else:

- **Where it stands** — what is built and merged, what is half-done and where.
- **What was decided** — and against which alternative, so the next session does
  not reopen a settled question by accident.
- **What is next** — the smallest thing worth doing, and what would block it.

Progress belongs here, not in [`../map_rebuild.md`](../map_rebuild.md) or
[`../realtime_map.md`](../realtime_map.md). Those say what we mean to do; a
handoff says what happened. A plan edited to record progress stops being readable
as intent.

The map track that predates this folder keeps its own:
[`../new_map_representation/handoffs/`](../new_map_representation/handoffs/),
which is era S's. Anything about the area as a whole — the layers, the eras, the
search over them — goes here.
