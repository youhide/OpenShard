# Roadmap

Order, not dates.

The roadmap is split by phase. Unfinished work has one canonical home:
[`backlog/`](backlog/README.md).

## Structure

- A roadmap file must not exceed 500 lines. Split a growing phase into a
  directory with a local `README.md` before it reaches that limit.
- Phase files record built state and technical context. Open task state belongs
  only in the consolidated backlog.
