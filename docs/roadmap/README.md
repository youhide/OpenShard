# The roadmap: what is left of it

**This directory was a holding area, and it is now empty of phase records.** It
held what the roadmap still carried for the domains that had not been migrated to
the documentation canon; every one of those records has been claimed by the
domain whose code it describes, and lives in that domain's `evidence/`.

`npc` was the last domain out, on 2026-09-03, and it took the whole
`06-gameplay/` directory with it — the five files left there were all its own.
What is built and what is open about people and creatures is
[`docs/npc/README.md`](../npc/README.md).

Two things do not live here and never did:

- **The order of work** is [`plans/roadmap/PLAN.md`](../../plans/roadmap/PLAN.md).
  A plan carries no progress and this page carries no queue.
- **The status of a domain** is that domain's README. The domain table in
  [`docs/README.md`](../README.md) is the index of them.

The roles a document can have, and the rule that puts each one in its place, are
in [`docs/README.md`](../README.md).

## What is still here, and why

Neither of the two backlogs is a phase record, and neither has a single domain to
go to:

- [`backlog/gameplay.md`](backlog/gameplay.md) — the data-table and
  Felucca-converter findings. Its rows belong to four domains at once, so each
  batch lifted its own rows into its README's "what is open" rather than cutting
  the record. It stays as the one place the whole sweep can still be read in
  order.
- [`backlog/later.md`](backlog/later.md) — the ideas that wait for an engine that
  stands on its own.

And one policy, which is about the repository rather than about a domain:

- [`client-files.md`](client-files.md) — none of the client's own files are in
  this repository and none will be.
